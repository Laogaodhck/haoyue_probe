# 浩玥照片工具

> 老高 · QQ 846193

对标腾讯浏览器「帮小忙」证件照工具的**纯前端单机离线**实现。
全部图像处理在浏览器本地完成（Canvas + WebAssembly 人像分割），**不调用任何后端服务或外部 API**，断网可完整运行。

## 两种使用方式

### 1. 桌面应用（推荐）

```bash
npm install        # 首次安装依赖
npm run dist       # 打包 Windows 安装包 + 便携版
```

产物输出在 `E:\electron-dist\haoyue-idphoto\`：
- `浩玥照片工具 Setup 1.0.0.exe`（NSIS 安装版）
- `浩玥照片工具_便携版.exe`（免安装单文件）

开发调试：`npm start` 直接启动 Electron 窗口。

### 2. 浏览器运行

1. 双击 `start.bat`（需要本机装有 Node.js 或 Python，仅用于起本地静态服务）
2. 浏览器自动打开 `http://localhost:8410/`
3. 手机访问：与服务处于同一局域网时，用控制台打印的局域网地址即可

> 也可以用任意静态服务器（如 `python -m http.server 8410`）。
> 直接双击 `index.html`（file:// 协议）无法加载本地 WASM 模型，页面会给出提示。

## 功能

| 功能 | 说明 |
| --- | --- |
| AI 人像分割 | MediaPipe Selfie Multiclass（六分类：头发/皮肤/衣服细分，本地 WASM 推理） |
| 一键换底 | 白 / 红 / 蓝 / 深蓝 / 灰 + 自定义色 |
| 手动修补 | 笔刷修补（恢复人像）/ 擦除（清除背景），大小可调，支持撤销 |
| 边缘羽化 | 0–8px 可调，消除抠图硬边 |
| 规格模板 | 一寸 / 小二寸 / 二寸 / 大二寸 / 护照 / 签证 / 驾驶证 / 社保照（8 种，含毫米尺寸与 300DPI 像素） |
| 裁剪调整 | 拖动平移、滚轮/双指缩放，头顶线 / 眼线 / 下巴线参考线 |
| 单张导出 | PNG（写入 pHYs）/ JPEG（写入 JFIF 密度），真实 300DPI 元数据 |
| 六寸排版 | 1800×1200 @300DPI 自动排布最多张数，含裁切参考线 |

## 操作流程

**上传 → 抠图换底 → 规格调整 → 导出** 四步完成：

1. **上传**：点击 / 拖拽 / Ctrl+V 粘贴照片
2. **抠图换底**：自动分割后选背景色，必要时用笔刷修补发丝边缘
3. **规格调整**：选择证件规格，拖动缩放让人像对齐参考线
4. **导出**：下载单张成品照或六寸相纸排版图

## 技术要点

- **分割模型**：优先 `selfie_multiclass_256x256.tflite`（背景/头发/身体皮肤/面部皮肤/衣服/配饰六分类，人像 = 1 − 背景置信度，发丝与衣服边缘更精确）；加载失败自动回退 `selfie_segmenter.tflite`（float16 二分类）。遮罩经硬阈值二值化（≥0.5），边缘无羽化晕边
- **合成管线**：预览与导出共用同一变换模型（`x_out = x_work × scale + tx`），笔刷直接编辑工作分辨率蒙版，导出时按需重合成保证清晰度
- **DPI 元数据**：PNG 手工注入 pHYs 块（含 CRC32），JPEG 修补/插入 JFIF APP0 密度字段，打印软件可识别真实物理尺寸
- **排版算法**：遍历列×行组合取容纳张数最多、留白最小者，裁切线贯通间隙便于裁剪

## 注意

- 分割质量取决于原图：建议正面、光线均匀、背景与人像区分度较高的照片
- 人像分割模型对多人物场景取整体人像区域，请使用单人照
